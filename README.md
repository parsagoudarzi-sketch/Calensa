

\# Calensa



A modern Chrome extension for tracking important dates and calculating age.



\## Features



\- Countdown to important dates

\- Accurate age calculation

\- Gregorian and Solar Hijri calendar support

\- Persian and English interface

\- Light and Dark themes

\- Save multiple events



\## Technologies



\- HTML

\- CSS

\- JavaScript

\- Chrome Extensions Manifest V3
